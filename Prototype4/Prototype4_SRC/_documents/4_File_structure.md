# File Structure

The ./Core/Src/main.c file is generated by STM32CubeMX and contains the main loop and is the entry point of the program. This file should not be edited beside three specific sections:

```c
/* USER CODE BEGIN Includes */
#include "cmc_app_logic.h"
/* USER CODE END Includes */

/* USER CODE BEGIN 2 */
cmc_app_init();
/* USER CODE END 2 */

/* Infinite loop */
/* USER CODE BEGIN WHILE */
while (1)
{
  cmc_app_process(); // Start main application logic loop
  /* USER CODE END WHILE */
}
```

This makes sure most of the code for the system is separated from the generated code and makes it easier to update the generated from STM32CubeMX code without worrying about merge conflicts. 

## Reference code files for build

CMake is used for building the code, and the CMakeLists.txt file contains the build instructions. 

**CMakeLists.txt files:**

`/cmake/stm32cubemx/CMakeLists.txt`  
This file is generated by STM32CubeMX and contains the build instructions for the generated code. This file should not be edited.

`/CMakeLists.txt`  
This file in root folder contains the build instructions for the code and has a separate secton `# Add sources to executable` for adding the cmc_ files for the build. This file can be edited by the user and is not generated by STM32CubeMX.
