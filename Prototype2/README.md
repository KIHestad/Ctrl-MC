# Arduino Motorcycle Controller Software - PROTOTYPE 2

This was the second prototype made during the period: July 2023 to Oct 2025. It was a simplified prototype based on one display units only. A custom PCB was made with a 2.4" OLED display, connected to a hall sensor for reading speed and an IR sensor for reading engine RPM. It was fitted to KI Hestad's adventure Motorcycle: Cagiva 750 Elefant.

Three videos where made explaining this prototype, check here for more info: 
* 1) Building a (better) Motorcycle Computer - https://youtu.be/J_AsExU7qkA?si=Gz2zUCPkYnKkuf4s
* 2) DIY Digital Speedometer - https://youtu.be/IC0Ai5frQ9I?si=YTvt7CZIG6abZeez
* 3) Custom Digital Motorcycle Instrument - Done! https://youtu.be/mAw5n_MP_k8?si=bNnLh9jdNJ4qRK95

This was just a standalone prototype for learing and testing. Neither the code or PCB is not to be used in further development.
